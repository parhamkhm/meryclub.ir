# Mery Coffee Club — Menu Photo Prompts (for Nano Banana / Gemini)

## How to use this

1. Copy the **STYLE PREFACE** below once.
2. For each item, paste: `STYLE PREFACE + that item's one-line description`.
3. Generate, download, and send me the results (or drop them straight into `assets/img/menu/` using the filename shown — that's the name the site will expect once we wire real photos in).
4. When real photography replaces an AI shot later, just send the new file with the same filename and I'll swap it in — no code changes needed.

**Important limitation to know going in:** AI image generators are unreliable at rendering small legible text (like a "MERY" logo on a cup). Don't fight this — the prompts below deliberately use **plain, unbranded cups/glassware**. If you want the logo on the cup, that's a 5-second edit for me to overlay afterward on a clean shot; asking the AI to render it directly usually comes out garbled.
